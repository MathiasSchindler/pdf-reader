dependency-free browser PDF rendering

pdf-crumb.js

A small experimental PDF renderer for the browser. It parses PDF objects and content streams directly, paints pages to canvas, and ships as a single minified JavaScript file for simple embedding.

Use It

The normal embeddable file is dist/pdf-crumb.viewer.min.js. It keeps stable rendering features, including image XObjects and browser-loaded embedded CFF fonts, while leaving diagnostics out.

<canvas id="page"></canvas>
<script type="module">
  import { loadPdfCrumb } from "./dist/pdf-crumb.viewer.min.js";

  const pdf = await loadPdfCrumb("./example.pdf");
  await pdf.renderPage(0, document.getElementById("page"), { scale: 1.5 });
</script>

Builds

  • full: development build with audit output and experimental embedded outline rendering.
  • viewer: default third-party build for general PDF display.
  • text: smallest profile for text/vector-only PDFs; image XObjects are disabled.

Open Source

The project is released under CC0-1.0. The code base was written with substantial LLM assistance, mostly GPT-5.5, with human direction, testing, and review throughout.

pdf-crumb.js is experimental software, not a conformance-grade PDF implementation.
